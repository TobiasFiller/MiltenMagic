# Milten Magic
Milten adds a Gothic(video game) inspired Magic System to Minecraft.

## Spells
- Teleportation
- Fire Arrow
- Fire Charge
- Fire Rain
- Levitation
- Absorption
- Resistance
- Magnetism
- Magical Protection

### Planned Spells

- Dirtfill

- Mob Spawner Creation
- Button Link

- Summon Stone Golem
